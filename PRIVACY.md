# Privacy

This scaffold is local-first and blueprint-only.

It does not make network calls, does not collect analytics, does not add tracking beacons, does not require API keys, does not require OAuth, and does not write data to Make or AdPages.

Sample inputs are read from local JSON files. Generated outputs are written only when the local CLI is run with an output directory.

If this becomes a hosted Make app later, the privacy policy must be updated before publication to describe the hosted API, auth method, data retention, logs, subprocessors, support contact, and deletion process.
